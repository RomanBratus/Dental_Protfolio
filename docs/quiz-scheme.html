Схема роботи тесту підбору системи

Візуалізація логіки класу TreatmentQuiz та методу calculateResult() для елемента id="quiz-container". Тест із 3 питань послідовно звужує вибір до однієї з 4 ортодонтичних систем.

Marco Rosa — діти 6–12 років
Mini Master® Brackets — швидкість / прикус
GC Chic — максимальна естетика
Invisalign — варіант за замовчуванням

Якщо у кроці 3 обрано вік 6–12 років — будь-яка комбінація відповідей дає Marco Rosa.

Нюанси та крайні випадки

Вік 6–12 перевизначає все

Правило віку стоїть першим: навіть при меті «Прикус» або пріоритеті «Швидкість» дитині 6–12 років буде запропоновано Marco Rosa.

«Прикус» завжди → Mini Master® Brackets

Мета «Прикус та профіль» веде до Mini Master® Brackets навіть при пріоритеті «Непомітність», бо правило швидкості/прикусу перевіряється раніше.

⚠ Дитяча мета + дорослий вік

Комбінація «Огляд дитини» + вік 13+ дає Invisalign (за замовчуванням), бо правило GC Chic вимагає goal !== 'child'. Можливо, варто виправити на GC Chic або окрему логіку.

Неможливо завершити порожнім

Кнопка «Далі» заблокована (disabled), доки не обрано відповідь на поточному кроці — тест завжди має 3 відповіді.
